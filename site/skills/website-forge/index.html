Website Forge

From natural-language brief to a complete working website. Original art direction, functional implementation and evidence-based verification.

Build without generic AI slop

Choose a coherent visual identity, use authentic brand assets, write specific copy and implement purposeful motion. Avoid repetitive cards, unnecessary gradients and fake functionality.

Development workflow

  1. Understand business goals, audience, routes and required integrations.
  2. Plan visual language, content and acceptance criteria.
  3. Implement every required route and functional flow using the existing stack.
  4. Review responsive layouts, accessibility, SEO and performance.
  5. Run real build checks and browser tests; report actual results and blockers.

Install

git clone https://github.com/MDYUS/claude-code-skills.git
cd claude-code-skills
python3 scripts/install.py --project /path/to/project --skills website-forge

Replace the example project path, then open that project in Claude Code.
