# Website Forge

An instruction-based Agent Skill for turning natural-language briefs into complete, distinctive websites with functional implementation and evidence-based verification.

## Install in Claude Code
Copy the entire `website-forge` folder into your project's `.claude/skills/` directory, retaining `SKILL.md` and `references/`. Open Claude Code in the project and invoke `/website-forge` followed by your website brief. If already installed, review and replace only with your permission.

Example:

```
/website-forge Create a premium interior design website with Home, Services, Projects, About and Contact, using our actual brand assets. Build functional enquiries, responsive pages and technical SEO. Avoid generic AI aesthetics and verify the site in a browser.
```

Other Agent Skills-compatible coding tools may use different installation paths. Consult their current documentation. The skill does not include an AI model, browser runtime, API credits or automatic deployment. Its effectiveness depends on the agent and available tools. Live Claude Code invocation has not been tested.
