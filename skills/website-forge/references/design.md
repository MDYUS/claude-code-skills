# Art direction and anti-slop review

## Choose the visual language from the brief
| Website type | Useful direction | Avoid |
|---|---|---|
| Construction/interiors | Architectural photography, editorial typography, project case studies, clear enquiry journey | Fake project galleries, decorative 3D that hides content |
| Ecommerce | Strong product crops, usable filters, clear pricing and stock, accessible checkout | Overdecorated storefront, fake discounts and reviews |
| SaaS | Real product visuals, clear benefit hierarchy, workflow demonstrations, precise pricing | Generic glowing dashboard mockups, vague feature slogans |
| Portfolio | Distinctive typography, case-study narratives, carefully paced imagery | Identical cards, excessive animation, invented clients |
| Education | Course clarity, levels, schedules and accessible enquiry routes | Unsupported outcomes, badges and generic classroom photos |

Design for the actual brand; these are starting points, not mandatory templates.

## System
- Establish a small token set for colors, surface, text, border, focus, spacing, type and radii. Prefer fluid type with bounded min/max and a content-driven grid. Keep body reading width reasonable; avoid compressing mobile layouts into tiny text.
- Use one strong focal point per section. Establish hierarchy with scale, weight, contrast, whitespace and alignment, not excessive effects. Alternate composition when content calls for it, not randomly.
- Use real assets with permission and inspect their crop at target viewport sizes. Do not stretch images or put text on unreadable photos. Prefer consistent icon libraries over arbitrary mixed emoji.
- Specify interactive states: default, hover, focus-visible, disabled, pressed/selected, loading and error. Never rely on color alone to communicate meaning.
- Motion: prefer opacity/transform and purposeful timings; avoid animating layout on every scroll. Ensure content is visible if animation fails; honor prefers-reduced-motion. Use real video/3D only when assets, budget and performance allow it.

## Copy quality
Every heading should say something specific about the business or product. Remove filler such as "elevate your experience", "unlock your potential" and unsupported "industry-leading" claims. Use explicit CTAs with predictable destinations. Distinguish real facts from sample content. Never invent proof points.

## Review questions
1. Could this page belong to any unrelated business if the logo changed? If yes, improve specific content and art direction.
2. Is the primary action obvious within the first useful viewport? Does it work?
3. Does each section add new information or help a task?
4. Are visual patterns consistent without monotonous repetition?
5. Are images relevant, legally usable, sharp and correctly cropped?
6. Does mobile feel intentionally composed, rather than desktop squeezed down?
7. Are interaction states, keyboard focus and reduced motion respected?
